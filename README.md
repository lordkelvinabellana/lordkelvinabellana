# Lord Kelvin Abellana

Full stack developer and automation engineer in Bohol, Philippines. I build SaaS products, client portals, dashboards and AI features with human approval built in, from the first prototype to production.

- 3+ years shipping SaaS: Junior to Lead Frontend Developer to Product Owner on cloud cost products for AWS, GCP and Azure, then MVPs built from scratch with startup founders
- Now: client portals, scorecards, governed AI systems and automation for agencies and growing businesses
- Also: video editing and motion graphics for brands

## Stack

**Frontend:** React, Next.js, Vue, TypeScript, Tailwind CSS, shadcn/ui, Vuetify, three.js, GSAP  
**Backend:** Node.js, Python, FastAPI, REST APIs, webhooks, Supabase (Auth, RBAC, Postgres), PostgreSQL, Prisma, Cloudflare Workers and D1  
**AI:** OpenAI and Claude APIs, RAG (Pinecone, Supabase vectors), agents with approval queues  
**Cloud and DevOps:** AWS, GCP (Cloud Run), Terraform, Docker, GitHub Actions, Vercel, Render  
**Testing:** Vitest, Playwright, Cypress, property-based testing (fast-check)  
**Automation:** n8n, Make, Zapier  
**Design:** Figma
